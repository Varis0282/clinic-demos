# Clinic Website Demos

Five complete, themed demo websites for one fictional clinic (Arogyam Multispeciality Clinic, Indore) — built with Next.js 14 + Tailwind.

- `/` — showcase landing (pick a design)
- `/pulse` Classic Professional · `/aurora` Modern Animated · `/hearth` Warm & Friendly · `/onyx` Premium Luxury · `/paper` Minimal Editorial
- Each theme: Home, About, Services, Doctors, Contact + WhatsApp appointment booking, Hindi/English toggle

**Rebrand for a client:** edit `lib/config.ts` (name, city, phone, WhatsApp, map).

```bash
npm install
npm run dev
```
